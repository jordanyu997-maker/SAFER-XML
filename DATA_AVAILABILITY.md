# Data and Code Availability

## Ready-to-paste manuscript text

The implementation, registered experiment protocols, frozen benchmark manifests, Android resource inputs, task definitions, prompts, and retrieval traces underlying this study are available in the SAFER-XML artifact repository at https://github.com/jordanyu997-maker/SAFER-XML. The frozen benchmark comprises 40 open-source Android applications, 110 XML repair tasks, 136 high-confidence XML-safe findings, and 30 boundary findings. Model-generated outputs, detailed run logs, quantitative result tables, and the manuscript source are not included in the public repository. Immutable input archives and a repository-wide `SHA256SUMS` file are provided to verify file integrity. The analyzed Android resources remain subject to their upstream open-source licences. A versioned archival DOI will be added upon deposit.
